This is Dataset Assembly Studio, a local tool for reviewing, curating, and exporting LeRobot datasets — without ever modifying the source data.

Start on the Sources tab. Point the app at your dataset folder, and it discovers and validates every LeRobot dataset automatically. Claim one, and you can save drafts, approve immutable checkpoints, or exclude a source.

Next, set up the Output contract: the final dataset name and folder, and the two cameras — a fixed wrist camera plus one second camera, typically front.

In Cameras, map each source view to wrist, the second camera, or omit it. Each preview plays a real representative episode.

In Joints, the app automatically maps the source's action and state vectors to the canonical six-joint SO-101 order, with manual selectors if needed.

Episodes is where you build your selection. The diversity sampler clusters similar tasks and stages an exact count per variant, and the gallery lets you browse, preview, and stage episodes. Everything lands in a temporary tray.

In Tasks, review that tray, prepare a shared final prompt, and commit episodes into the real recipe.

When a dataset is ready, go back to Sources and approve a checkpoint to freeze it.

Balance then combines every approved checkpoint across all datasets, with deterministic per-prompt and per-group caps to keep the dataset balanced.

Run Preflight to catch any remaining blockers — cameras, joints, missing media, or blank prompts.

Finally, in Export, reconfirm the two cameras and start the verified background export. The app normalizes every episode to LeRobot v2.1, checks the result, and lets you download it as a tarball.
