TWO-CAMERA CONTRACT

One canonical output, many sources

Every exported dataset carries a fixed wrist view plus a selectable second camera — rebuilt to a single consistent encoding, no matter which source it came from.

VALIDATION-FIRST

Nothing enters silently

Datasets are validated before use; preflight blocks export on any incompatibility.

NON-DESTRUCTIVE

Sources stay read-only

Curation, editing, and export never modify an original source dataset.

DETERMINISTIC

Balanced, reproducible

Per-prompt and per-group caps spread approved checkpoints evenly across tasks.

VERIFIED HANDOFF

v2.1 output

Rebuilt indices, edited prompts, and optional tarball packaging for handoff.
